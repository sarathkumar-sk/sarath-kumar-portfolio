# Sarath Kumar S K — Robotics Engineer

Portfolio of **Sarath Kumar S K**, a robotics engineer studying MSc Robotics at
the University of Manchester. Work spans autonomous navigation and SLAM,
computer vision and deep learning for industrial inspection, cascade PID control
and real-time embedded systems.

**Live site:** https://sarathkumar-sk.vercel.app

## Stack

React 18, TypeScript, Vite, Tailwind CSS, Motion (Framer Motion), three.js via
React Three Fiber.

The hero renders a real-time 3D robot lit by a scroll-driven light; the same
light source drives the specular treatment across the rest of the page. Light
and dark themes are both first class.

## Running locally

```bash
npm install
npm run dev     # http://localhost:8080
npm run build   # production build to dist/
npm run lint
```
